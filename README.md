# FindPRO

App Android que conecta particulares con profesionales para la contratación de servicios. Incluye autenticación, gestión de perfiles y mapas integrados.

## Requisitos

- Android Studio (versión recomendada: Flamingo o superior)
- Gradle 8.10.2
- JDK 17
- Android SDK API 35

## Cómo abrir en Android Studio

1. Clona el repositorio
2. Abre Android Studio
3. Selecciona "Open" y elige la carpeta del proyecto
4. Espera a que Gradle sincronice las dependencias

## Generar APK

```bash
./gradlew assembleDebug
```

El APK se genera en: `app/build/outputs/apk/debug/app-debug.apk`
