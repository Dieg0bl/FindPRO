# Descripción para la sección "About" de GitHub

## Versión Concisa (para About section):

**Aplicación Android de marketplace de servicios profesionales** que conecta particulares con profesionales de forma geolocalizada. Desarrollada con Kotlin, Jetpack Compose, Firebase y Mapbox siguiendo Clean Architecture.

## Versión Alternativa (más técnica):

Plataforma móvil Android para conectar usuarios con profesionales locales. Stack: Kotlin + Jetpack Compose + Firebase + Mapbox. Arquitectura modular con Clean Architecture, Hilt DI y Navigation Compose.

## Versión para Reclutadores:

Aplicación Android de marketplace que conecta clientes con profesionales locales. Tecnologías modernas: Kotlin, Jetpack Compose, Firebase. Arquitectura escalable y código limpio siguiendo mejores prácticas de Android.

---

**Recomendación**: Usar la "Versión Concisa" en la sección About de GitHub ya que es clara, informativa y equilibrada para desarrolladores y reclutadores.
